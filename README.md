# 📚 AI Study Assistant

An intelligent web application that provides detailed explanations on any topic using Groq's high-speed AI models.

## ✨ Features

- **Multiple AI Personas**: Choose from 4 different teaching styles
  - 🎓 Friendly Tutor - Beginner-friendly with analogies
  - 👨‍🏫 Academic Professor - Professional and detailed
  - 📖 Elaborate Explainer - Comprehensive breakdowns
  - ✍️ Concise Educator - Clear and focused

- **Interactive Interface**: Clean, modern UI with real-time responses
- **Copy to Clipboard**: Easily save explanations
- **Token Tracking**: See AI usage statistics
- **Fast Responses**: Powered by Groq's ultra-fast inference

## 🚀 Quick Start

### Prerequisites

- Python 3.8 or higher
- Groq API key ([Get it here](https://console.groq.com/keys))
